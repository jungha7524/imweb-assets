# imweb-assets

`jungha7524/imweb-factory` 템플릿이 쓰는 **이미지 자산**을 배포한다.

아임웹 코드 위젯 안에는 이미지 파일을 담을 수 없다. 여기에 올리고 위젯은 주소만 참조한다.

## 규칙

- **여기 올라간 것은 전부 공개된다.** 고객사의 실제 사진, 사람 얼굴이 나오는 사진,
  개인이 식별되는 이미지는 **올리지 않는다.** 그런 것은 아임웹에 직접 올린다
- 파일은 **생성기가 만든 것만** 올린다. 손으로 넣은 파일은 다음 생성 때 사라진다
- 경로는 `<템플릿>/<쓰임>/<이름>.png`
- 장당 300KB 이하 (모바일에서 여러 장이 한 번에 뜨는 자리다)

## meat-b2c/cut

한우 부위 도해 4장. 1200×900 (4:3) PNG.

| 파일 | 부위 | 용도 |
|---|---|---|
| `deungsim.png` | 등심 | 구이 · 스테이크 |
| `chaekkeut.png` | 채끝 | 구이 · 스테이크 |
| `ansim.png` | 안심 | 스테이크 · 수육 |
| `yangji.png` | 양지 | 국 · 찜 · 육개장 |

구이용 셋에 국거리(양지) 하나를 넣었다. 구이용만 있으면 선물용으로만 읽힌다.

`imweb-factory` 의 부위 도해 생성기가 만든다. **여기서 직접 고치지 않는다** —
고쳐도 다음 생성 때 덮어쓴다.
